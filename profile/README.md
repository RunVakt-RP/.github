## Om RunVakt RP

**RunVakt RP** är en svensk FiveM-server med fokus på kvalitativt, engagerande och långsiktigt rollspel.

Vårt mål är att skapa en levande värld där systemen finns för att stödja rollspelet – inte stå i vägen för det. Vi arbetar därför kontinuerligt med att utveckla och förbättra både tekniken bakom servern och upplevelsen för våra spelare.

RunVakt byggs med fokus på **kvalitet, immersion, stabilitet och genomtänkt design**.

🌐 **Webbplats:** https://runvaktrp.netwide.network/

## Vår utvecklingsfilosofi

### Immersion före onödig komplexitet

Tekniken ska förstärka rollspelet.

Vi försöker undvika system som tvingar spelaren ur upplevelsen genom onödiga menyer, kommandon, markörer eller andra element som inte passar naturligt in i världen.

Interaktioner ska där det är möjligt kännas som en del av miljön och rollspelet.

### Kvalitet före kvantitet

Fler funktioner innebär inte automatiskt en bättre server.

Vi prioriterar hellre färre, väl genomarbetade system än en stor mängd funktioner som saknar tydligt syfte eller inte håller den standard vi eftersträvar.

### En sammanhängande upplevelse

RunVakt ska kännas som **en server**, inte som en samling fristående scripts.

Därför arbetar vi för konsekvens mellan bland annat:

- UI och visuell design
- Interaktioner
- Terminologi
- Notifikationer
- Behörigheter
- Arbetsflöden
- Gameplay-system

### Prestanda och stabilitet

Prestanda är en viktig del av utvecklingen.

Vi eftersträvar resurser som är effektiva både på klient- och serversidan och undviker onödig belastning där det går.

### Underhållbar utveckling

RunVakt är ett långsiktigt projekt.

Kod och system ska därför vara möjliga att förstå, vidareutveckla och underhålla även när servern växer.

Vi eftersträvar:

- Tydlig struktur
- Modulär kod
- Återanvändbara komponenter
- Tydliga konfigurationer
- Dokumenterade integrationer
- Begränsade beroenden mellan system

## Open Source

Vissa projekt kan komma att publiceras när vi bedömer att de även kan vara användbara för andra utvecklare och communities.

Att ett repository är publikt innebär dock inte automatiskt att koden får:

- Redistribueras
- Säljas
- Paketeras om
- Publiceras på nytt
- Användas kommersiellt

Licensen i respektive repository gäller alltid.

Kontrollera därför alltid projektets `LICENSE` och dokumentation innan du använder eller modifierar koden.

---

## Bidrag

RunVakts repositories utvecklas i första hand för serverns egna behov och alla projekt tar därför inte emot externa contributions.

För repositories där bidrag accepteras ber vi dig läsa projektets dokumentation och eventuella contribution guidelines innan du öppnar en Pull Request.

Vid buggrapportering uppskattas så mycket relevant information som möjligt, exempelvis:

- Vad du försökte göra
- Förväntat resultat
- Faktiskt resultat
- Hur problemet kan reproduceras
- Relevanta loggar eller felmeddelanden

---

## Säkerhet

Säkerhetsproblem ska **inte rapporteras genom publika GitHub Issues**.

Detta inkluderar bland annat:

- Sårbarheter
- Exploits
- Autentiseringsproblem
- Behörighetsproblem
- Möjligheter att kringgå system
- Information som kan påverka serverns säkerhet

Sådana problem ska istället rapporteras privat till RunVakt.
